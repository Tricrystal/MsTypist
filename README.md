# MsTypist

> A Java tool fill .docx with .xlsx just like a typing lady.

读取一个 Excel 数据表和一组 Word 模板（`.docx`），把表格中**每一行数据**按模板批量生成对应的 Word 文档：正文、表格、页眉页脚以及**文件名**中的占位符都会被该行对应列的值替换，并按指定的"标识列"分文件夹输出。

> 典型场景：给一批店铺/客户，每人生成一套起诉状、授权委托书、证据清单等法律文书；或给一批员工生成通知书、证书等。

## 功能特性

- **图形界面**：单窗口依次选择模板文件（可多选）、Excel 数据表与输出目录，无需命令行
- **占位符替换**：`{{字段名}}` 语法，覆盖正文、表格（含嵌套）、页眉、页脚与模板文件名
- **按标识列分目录**：选择某一列，其值作为子文件夹名，每行数据各得一套文档
- **检查模板**：执行前列出模板占位符与 Excel 列名的对照，缺失列提前标记
- **稳定执行**：后台线程运行，界面不卡顿；单个模板失败只记录错误并继续
- **按显示格式读取**：`1` 就是 `1`，日期保持显示格式，数值不会变成 `1.0`
- **兼容旧系统**：字节码目标 Java 8，可运行于 Windows XP ~ Windows 11

## 环境要求

- 运行：JRE 8 及以上
- 构建：JDK 8+、Maven 3.6+

## 构建与运行

```bash
git clone https://github.com/Tricrystal/MsTypist.git
cd MsTypist
mvn package
java -jar target/MsTypist-gui.jar
```

## 使用步骤

### 1. 准备 Excel 数据表

- 后缀必须为 `.xlsx`；
- 所有工作表都会被遍历，每个表的**第一行是表头**，每个表头名即一个字段名，从第二行起每行是一条数据；
- 表头与模板中的占位符一一对应，例如表头 `被告`、`原告名`、`店铺名`。

### 2. 准备 Word 模板

- 后缀必须为 `.docx`（`.doc` 老格式会被忽略，请先在 Word 中另存为 `.docx`）；
- 把需要替换的位置写成 `{{字段名}}`，字段名与 Excel 表头完全一致，例如：

  > 委托人姓名：`{{原告名}}`　被告：`{{被告}}`

- 模板**文件名**里也可以使用占位符，如 `起诉状（{{店铺名}}）.docx`；
- 没有任何占位符的模板也会被处理，相当于原样复制到各个输出文件夹。

### 3. 运行并选择标识列

1. 打开程序，依次选择**模板文件**（可按住 Ctrl 多选）、**Excel 数据表**、**输出目录**；
2. 在"目录命名列(标识列)"下拉框中选择用哪一列的值命名输出子文件夹；
3. 点击 **【检查模板】** 核对占位符与 Excel 列名的对照（`√ {{被告}} = Excel列[被告]`，缺失列标 ×，并汇总未被引用的列）；
4. 确认无误后点击 **【开始执行】**，界面实时输出每行结果与统计（成功/失败/跳过）。

### 4. 查看输出

```text
output/
├── 老人与海/
│   ├── 起诉状（老人与海）.docx          ← 文件名中的 {{店铺名}} 已替换
│   ├── 授权委托书.docx
│   └── 证据清单.docx
├── 挪威的森林/
│   └── ……
└── 黄金时代/
    └── ……
```

## 占位符规则

| 位置 | 语法 | 行为 |
|---|---|---|
| 正文、表格（含嵌套）、页眉、页脚 | `{{字段名}}` | 替换为该行该列的文本值 |
| 模板文件名 | `{{字段名}}` | 替换为该行该列的文本值 |
| 对应单元格为空 | — | 占位符被直接删除（文件名中同样删除） |

- 字段名区分大小写，必须与表头完全一致；
- 占位符跨多个 run 断裂也能正常识别（中文输入法下 Word 常把一个词拆成多段）；
- 替换后的文本继承占位符所在位置的样式。

## 实现原理

```
模板 *.docx（可多选） ┐
                      ├→ 逐行渲染（poi-tl）→ 输出目录/<标识列值>/<替换后文件名>.docx
Excel *.xlsx（首行=表头） ┘
```

1. 读取 Excel：遍历所有工作表，首行作表头，其余每行转成 `Map<字段名, 单元格文本>`，保持原有行序；
2. 标识列为空的行跳过并提示原因；
3. 对每行数据，先按标识列的值创建输出子文件夹，再对每个模板调用 poi-tl 的 `XWPFTemplate.compile(模板).render(行数据)` 完成替换，输出为新文件。

技术栈：[poi-tl 1.12.2](https://deepoove.com/poi-tl/) 模板引擎 · Apache POI 5.2.5 · Java Swing · Maven Shade（fat jar）。

## 注意事项

1. 标识列各行最好非空且互不相同：为空的行会被跳过；两行值相同会写入同一文件夹，同名文件后处理的行会覆盖先处理的行。
2. 空单元格即删除：某行某列为空时，模板中对应的 `{{字段}}` 会被删除而不是保留；如需保留默认值请补全数据。
3. Word 打开模板时产生的 `~$xxx.docx` 临时文件请不要选入模板。
4. Windows XP 需已安装 JRE 8（32 位）；Windows 7 及以上使用 JRE 8 ~ 21+ 均可。
